# HOPPER APK v0.1.0

First downloadable APK release of HOPPER.

## What is included

- Collection-based wagon journals
- Built-in camera screen for wagon photography
- OCR recognition of wagon numbers
- Notes for journals and individual wagon cards
- Manual wagon number editing
- Manual card reordering
- `PR` / `GR` wagon state marking
- Direction labels at the top and bottom of the journal
- Search across collections and inside journals
- Sharing as text
- Hopper file export and import with or without photos
- Theme, icon, text size, and photo quality settings

## APK in this release

- `HOPPER-universal-debug.apk`

## Installation

- Download the APK from the release assets
- Open it on your Android device
- If needed, allow installation from your browser or file manager

## Important note

- This release contains a universal debug build for easy installation and testing
- A signed release build can be added later
